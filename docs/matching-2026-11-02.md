## Source and data placement

The former file groupings crossed gaps in the original literal, jump-table, and
local-array storage. Each new source unit covers a contiguous owner span; the
compiler emits its C, jump tables, strings, constants, and local-array initializers.
Shared local headers retain the types and declarations used by the split units.
Adjacent units are kept together where their data layout permits it, including
float/double pools whose alignment depends on preceding constants. The splits
are build organization and do not claim recovered original translation units.

Complete image comparison also identified donor values that differ in Zero:

- Party-ball texture pointers use segmented addresses `0x03006C40`, `0x03006CA0`,
  and `0x03006D00`.
- Secondary-model eye spacing uses `0.5f, 0.4f, 0.3f`.
- The small-model squish reaction uses `0.65` / `0.65f` scale constants.

The ledger also records the actual address-style C names for two camera helpers
previously labeled with unrelated donor aliases at the same established addresses.
No raw instruction words, retail code blobs, or comparison exceptions were added.
